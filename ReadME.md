# Домашнє завдання №6: SQLAlchemy та PostgreSQL

Цей проєкт реалізує базу даних для навчального закладу за допомогою SQLAlchemy та наповнює її випадковими даними за допомогою бібліотеки Faker.

## Структура бази даних

Схема бази даних містить наступні таблиці:

- `groups` — навчальні групи.
- `students` — студенти, пов'язані з групами.
- `teachers` — викладачі.
- `subjects` — предмети із вказівкою викладача.
- `grades` — оцінки студентів із зазначенням дати отримання.

## Як запустити проєкт

### 1. Підготовка бази даних

Запустіть Docker-контейнер із PostgreSQL:

```bash
docker run --name some-postgres -p 5432:5432 -e POSTGRES_PASSWORD=mysecretpassword -d postgres
```

### 2. Налаштування середовища

Клонуйте репозиторій та встановіть залежності:

```
pip install -r requirements.txt
```

Створіть файл `.env` на основі `.env.example` та вкажіть ваші налаштування підключення:

```
DATABASE_URL=postgresql+psycopg2://postgres:mysecretpassword@localhost:5432/postgres
```

### 3. Міграції та наповнення даними

Застосуйте міграції для створення структури таблиць:

```
alembic upgrade head
```

Заповніть базу даних випадковими даними:

```
python seed.py
```

### 4. Виконання запитів

Для перевірки роботи всіх 10 основних запитів запустіть:

```
python test.py
```
